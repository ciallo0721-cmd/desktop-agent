# 文件整理

把目标目录里散落的文件按类型挪进子文件夹。**默认只演习（dry-run），不动任何文件。**

## 步骤

1. 确认目标目录。用户没说就默认 `workspace/`，问一句比猜错强。
   目标写绝对路径，比如 `C:/Users/nb666/Downloads`。

2. 先跑 dry-run，把计划原样念给用户：

```
python scripts/tidy.py "目标目录"
```

输出形如 `[计划] a.pdf → 文档/a.pdf`，结尾会打印「演习模式，没有动文件」。

3. 把计划里**最关键的三五行**摘给用户（多少文件、分了几类、有没有同名冲突），
   然后问一句「要真挪吗」。别把几十行计划全贴出来。

4. 用户同意后再执行：

```
python scripts/tidy.py "目标目录" --apply
```

5. 汇报结果：挪了多少、跳过了多少、冲突改名的有几条（脚本对重名会自动加 `_1`、`_2`）。

## 注意事项

- 脚本只挪**文件**，不动已经有同名子文件夹里的东西，也不递归进子文件夹。
- 隐藏文件（`.` 开头）和 `desktop.ini`、`Thumbs.db` 一律跳过，不碰。
- 分类表在 `references/by-type.md`，用户嫌分得太细/太粗时按那个改脚本里的
  `CATEGORY` 字典，改完再跑一遍 dry-run。
- 这是不可逆操作（挪走的位置变了），**没经过用户同意绝不加 `--apply`**。
